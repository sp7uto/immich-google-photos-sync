## Wiki publishing / Publikacja Wiki

The files `docs/wiki/Home.md` and `docs/wiki/Home-PL.md` are the canonical Wiki page sources maintained in this repository. **GitHub's Wiki is a separate Git repository** (`immich-google-photos-sync.wiki.git`); a commit to `main` does not publish Wiki pages automatically.

Files must be copied into that Wiki repository as `Home.md` and `Home-PL.md`, then committed and pushed using authorized Git access. The connection used to update the main repository does not offer a Wiki write operation.

Pliki `docs/wiki/Home.md` i `docs/wiki/Home-PL.md` to źródła stron Wiki. **Wiki GitHuba jest osobnym repozytorium Git**; publikacja na gałęzi `main` nie aktualizuje jej automatycznie. Aby uruchomić Wiki, należy skopiować te dwa pliki do repozytorium `immich-google-photos-sync.wiki.git` jako `Home.md` i `Home-PL.md` oraz wykonać commit i push z uprawnieniami zapisu.
